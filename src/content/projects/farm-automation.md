  id:
    - Saya membangun dan menerapkan sistem monitoring kandang ayam dan kontrol iklim secara real-time menggunakan Raspberry Pi dan Python sebagai pengendali utama. Data sensor dikumpulkan dari perangkat ESP32/ESP8266 yang diprogram menggunakan C++ dan dikirim ke Raspberry Pi.
    - Sistem ini tidak hanya memantau kondisi lingkungan, tetapi juga berfungsi sebagai pengendali utama kipas ventilasi untuk menjaga kestabilan iklim di dalam kandang dengan mode otomatis dan manual.   en:
    - I built and deployed a real-time poultry farm monitoring and climate control system using Raspberry Pi and Python as the central controller. Sensor data is collected from ESP32/ESP8266 devices programmed in C++ and sent to Raspberry Pi.
    - The system not only monitors environmental conditions but also acts as the main controller for ventilation fans to maintain stable climate conditions inside the poultry house with both automatic and manual modes. It runs continuously in a live farm environment, reducing manual intervention and improving operational reliability.
