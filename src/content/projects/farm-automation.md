description:
  - I built and deployed a real-time poultry farm monitoring and climate control system using Raspberry Pi and Python as the central controller. Sensor data is collected from ESP32/ESP8266 devices programmed in C++ and sent to Raspberry pi.
  - The system not only monitors environmental conditions but also acts as the main controller for ventilation fans to maintain stable climate conditions inside the poultry house with auto and manual mode. It runs continuously in a live farm environment, reducing manual intervention and improving operational reliability.
